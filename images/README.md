# Guide d'Ajout des Images Personnelles

## Instructions

Pour personnaliser votre portfolio avec vos propres images, placez les fichiers suivants dans le dossier `public/images/` :

### 1. Photo de Profil
**Fichier :** `profile.jpg` ou `profile.png`
- **Dimensions recommandées :** 400x400 pixels (carré)
- **Format :** JPG ou PNG
- **Utilisation :** Photo de profil dans le Hero et la section À Propos

### 2. Logos des Écoles

#### ENSPY
**Fichier :** `enspy-logo.png`
- **Dimensions recommandées :** 200x200 pixels
- **Format :** PNG avec fond transparent (préférable)
- **Utilisation :** Timeline - Master of Engineering

#### Université de Ngaoundéré
**Fichier :** `universite-ngaoundere-logo.png`
- **Dimensions recommandées :** 200x200 pixels
- **Format :** PNG avec fond transparent (préférable)
- **Utilisation :** Timeline - Bac+2 Mathématiques Pures

#### Coursera (Optionnel)
**Fichier :** `coursera-logo.png`
- **Dimensions recommandées :** 200x200 pixels
- **Format :** PNG avec fond transparent (préférable)
- **Utilisation :** Timeline - Certification Machine Learning

## Comment Ajouter les Images

1. Téléchargez ou préparez vos images
2. Renommez-les selon les noms ci-dessus
3. Placez-les dans le dossier `public/images/`
4. Le portfolio les chargera automatiquement

## Images Temporaires

En attendant vos vraies images, le portfolio utilise des images de placeholder depuis Unsplash. Une fois que vous ajouterez vos images dans `public/images/`, elles remplaceront automatiquement les placeholders.

## Conseils

- Utilisez des images de haute qualité
- Pour les logos, préférez le format PNG avec fond transparent
- Optimisez vos images pour le web (compression sans perte de qualité)
- La photo de profil doit être professionnelle et bien cadrée
